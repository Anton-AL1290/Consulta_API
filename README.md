# Consulta_API
Ejercicio sencillo para consultar un API con Python.

Este ejercicio fue hecho para la clase de programación para ciberseguridad con el objetivo de entender los conceptos de las API y el web-scratching, utilizados para herramientas de ciberseguridad o de programación web.

El código manda una petición hacia el API de PokeApi, permitiendo obtener datos del pokemon que te interese conocer más a fondo << Como si se tratase de buscar en la pokedex >> Tan sólo al ejecutar el código introduce el nombre del pokemon que quieras consultar, por ejemplo, bulbasaur.

El resultado será el siguiente:

--- Información del Pokémon ---
Nombre: Bulbasaur
ID: 1
Altura: 7
Peso: 69
Tipos:
- grass
- poison
